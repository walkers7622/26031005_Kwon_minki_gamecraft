\# \[게임 기획서] Boss Raid



\*\*작성자:\*\* 권민기  

\*\*학번:\*\* 26031005  

\*\*작성일:\*\* 2026-10-14  

\*\*과제명:\*\* Boss Raid



\---



\## 1. 게임 개요

제한시간 안에 보스 한 마리를 쓰러뜨리는 \*\*탑다운 보스전 액션 게임\*\*입니다.  

플레이어는 아레나 안에서 자유롭게 이동하며 보스의 공격을 피하고, 자동으로 보스를 향해 발사되는 총알로 보스의 체력을 깎습니다.



\## 2. 게임 목적

\*\*제한시간(90초) 안에 보스를 처치\*\*하는 것이 목표입니다. 남은 시간이 많을수록 높은 점수를 획득합니다.



\## 3. 조작 방법

| 구분 | 입력 방식 | 설명 |

| :--- | :--- | :--- |

| \*\*이동\*\* | 방향키 (`↑`, `↓`, `←`, `→`) | 아레나 안에서 상하좌우로 이동 |

| \*\*공격\*\* | 자동 발사 | 별도 입력 없이 일정 주기로 보스 방향을 향해 총알 발사 |

| \*\*대시\*\* | `Shift` | 이동 방향으로 짧게 돌진, 대시 중 무적 (쿨타임 있음) |

| \*\*시작 / 재시작\*\* | `Spacebar` | 타이틀 화면과 결과 화면에서 게임 시작·재시작 |



\## 4. 게임 규칙

\* \*\*HP(생명력) 시스템:\*\*

&#x20; \* 플레이어 HP는 100에서 시작하며, 보스의 공격(탄막, 돌진)에 맞을 때마다 10씩 감소합니다.

&#x20; \* HP가 0이 되면 즉시 \*\*게임 오버(패배)\*\*로 처리됩니다.

\* \*\*무적 시간:\*\* 피격 직후 연속으로 HP가 깎이지 않도록 피격 후 1초간 무적 시간을 부여합니다.

\* \*\*대시:\*\* 대시 중에는 짧게 무적 상태가 되며, 사용 후 쿨타임이 지나야 다시 사용할 수 있습니다.

\* \*\*제한시간:\*\* 게임 시작과 동시에 90초 카운트다운이 시작되며, 0초가 되면 즉시 패배합니다.

\* \*\*보스 HP:\*\* 플레이어의 총알에 맞을 때마다 감소하며, 0이 되면 보스가 처치됩니다.

\* \*\*아이템:\*\* 아이템은 사용하지 않습니다 (순수 보스전 + 회피 스코프).



\## 5. 점수 / 승부 규칙

\* \*\*클리어 점수:\*\* 보스를 처치했을 때의 \*\*남은 시간(초)에 비례\*\*하여 점수를 지급합니다.

\* \*\*패배 시:\*\* 점수는 0점으로 처리하고 패배 사유(시간 초과 / HP 0)를 결과 화면에 표시합니다.

\* 게임 종료 시 결과 화면에 최종 점수와 남은 시간을 표시합니다.



\## 6. 게임 시작 조건

프로그램 실행 후 타이틀 화면(게임 제목 + 안내 문구)이 표시되며, `Spacebar` 입력 시 전투 화면으로 전환되어 게임이 시작됩니다.



\## 7. 게임 종료 조건

\* \*\*승리:\*\* 제한시간(90초) 안에 \*\*보스 HP를 0으로 만듦\*\*

\* \*\*패배 ①:\*\* 제한시간이 0초가 됨 (시간 초과)

\* \*\*패배 ②:\*\* 플레이어 HP가 0이 됨

> 세 조건 중 하나를 만족하면 즉시 게임이 종료되고 결과 화면으로 전환됩니다. 결과 화면에서 `Spacebar`를 누르면 게임이 재시작됩니다.



\## 8. 플레이어 행동

\* \*\*이동:\*\* 방향키 입력에 따라 상하좌우로 이동 (아레나 경계를 벗어나지 않음)

\* \*\*공격:\*\* 보스 방향을 향해 자동으로 총알을 일정 주기마다 발사

\* \*\*대시:\*\* `Shift` 입력 시 이동 방향으로 짧게 돌진하며 무적 (쿨타임 동안 재사용 불가)

\* \*\*피격:\*\* 보스의 공격에 맞으면 HP 10 감소 + 1초 무적 시간 부여 (무적 중 깜빡임 연출)



\## 9. 적 / 장애물 / 아이템 행동

\* \*\*보스 (Boss):\*\*

&#x20; \* 아레나 중앙 부근에서 시작하며, 일정 간격으로 3가지 패턴 중 하나를 사용합니다.

&#x20; \* 체력이 \*\*50% 이하\*\*가 되면 2페이즈로 전환되어 패턴 사용 간격이 짧아지고 공격이 빨라집니다.

\* \*\*보스 패턴:\*\*

&#x20; | 패턴 | 설명 |

&#x20; | :--- | :--- |

&#x20; | \*\*돌진\*\* | 경고 표시 후 플레이어 방향으로 직선 돌진 |

&#x20; | \*\*원형 탄막\*\* | 보스 주변으로 여러 방향의 탄을 동시에 발사 |

&#x20; | \*\*조준탄\*\* | 플레이어 위치를 향해 탄을 연속 발사 |

\* \*\*아이템:\*\* 미사용 (해당 없음)



\## 10. 게임 화면 구성

1\. \*\*상단 HUD:\*\* 왼쪽 플레이어 HP, 정중앙 남은 시간(mm:ss, 카운트다운), 오른쪽 점수 표시

2\. \*\*보스 체력바:\*\* 화면 상단에 보스 HP를 막대로 표시

3\. \*\*중앙 아레나:\*\* 플레이어, 보스, 총알이 배치되는 전투 영역

4\. \*\*타이틀 화면:\*\* 게임 제목("Boss Raid") + 시작 안내 문구

5\. \*\*결과 화면:\*\* 승리 / 패배 여부 + 패배 사유 + 최종 점수 + 재시작 안내 문구



\## 11. 게임 진행 흐름

```text

\[타이틀 화면]

&#x20;     │ (시작 입력: Space)

&#x20;     ▼

\[전투 화면 진입] ─── (이동 / 자동사격 / 대시 / 보스 패턴 / 충돌판정 반복)

&#x20;     │

&#x20;     ├──────────────────┬──────────────────┐

&#x20;     ▼                  ▼                  ▼

\[승리: 보스 HP 0]  \[패배: 시간 초과]  \[패배: 플레이어 HP 0]

&#x20;     │                  │                  │

&#x20;     └──────────────────┼──────────────────┘

&#x20;                        ▼

&#x20;                 \[결과 화면] (점수 / 결과 표시)

&#x20;                        │

&#x20;                (Space 입력 시 재시작)

```



\## 12. 주요 게임 객체 목록

\* `Player`: 플레이어 캐릭터, 이동, 대시, 자동 발사 담당

\* `Boss`: 보스, 체력과 페이즈 관리, 패턴 실행

\* `BossPattern`: 보스 패턴의 부모 클래스 (`ChargePattern`, `RingPattern`, `AimedPattern`이 상속)

\* `Bullet`: 플레이어와 보스가 발사하는 총알 (오브젝트 풀링)

\* `GameMain`: 게임 전체 상태(시작/전투/게임오버), 타이머, 점수, HUD, 결과 화면을 총괄 관리



\## 13. 프로그램 클래스 구성



\### 클래스 목록 및 관계



```

GameMain (G2AppBase 상속)

├─ Player (IDamageable)

├─ Boss (IDamageable)

│   └─ BossPattern (추상 클래스)

│       ├─ ChargePattern

│       ├─ RingPattern

│       └─ AimedPattern

└─ Bullet (여러 개, 풀링 관리)

```



`GameMain`이 게임 전체 상태(Start/Playing/GameOver)와 흐름을 관리하며, `Player`, `Boss`, `Bullet` 객체를 생성·갱신·렌더링·해제한다.



\### 클래스별 역할



\*\*GameMain\*\*

\- 게임 전체 흐름(타이틀 → 전투 → 결과) 관리

\- 입력 처리, 충돌 판정, 제한시간 카운트다운, 점수 관리

\- 주요 멤버 변수: `\_currentState`, `\_remainingTime`, `\_score`, `\_isVictory`, `\_bullets`

\- 주요 멤버 함수: `Initialize()`, `Update()`, `Render()`, `StartGame()`, `HandleCollisions()`



\*\*Player\*\*

\- 플레이어 이동, 대시, 자동 발사, HP/무적 관리

\- 주요 멤버 변수: `X`, `Y`, `CurrentHP`, `MaxHP`, `IsInvincible`, `DashCooldown`

\- 주요 멤버 함수: `Initialize()`, `Update()`, `Render()`, `TakeDamage()`, `Dash()`, `Reset()`

\- 이벤트: `OnFireBullet`(총알 발사 시), `OnDied`(HP 0 시)



\*\*Boss\*\*

\- 보스의 HP, 페이즈 전환, 패턴 선택 및 실행 관리

\- 주요 멤버 변수: `X`, `Y`, `CurrentHP`, `MaxHP`, `Phase`, `\_patterns`

\- 주요 멤버 함수: `Update()`, `Render()`, `TakeDamage()`, `ChangePhase()`

\- 이벤트: `OnDied`(HP 0 시)



\*\*BossPattern (추상 클래스)\*\*

\- 모든 보스 패턴의 공통 틀 (실행 시작, 갱신, 종료 여부 확인)

\- 주요 멤버 함수: `Start()`, `Update()`, `IsFinished()` — 자식 클래스가 각자 재정의(오버라이드)

\- 자식 클래스: `ChargePattern`(돌진), `RingPattern`(원형 탄막), `AimedPattern`(조준탄)



\*\*Bullet\*\*

\- 총알의 이동과 활성 상태 관리 (오브젝트 풀링), 발사 주체(플레이어/보스)와 방향을 가짐

\- 주요 멤버 변수: `X`, `Y`, `DirX`, `DirY`, `Active`, `Speed`, `Owner`

\- 주요 멤버 함수: `Fire()`, `Update()`, `Render()`, `Deactivate()`



\*\*IDamageable (인터페이스)\*\*

\- 피해를 받을 수 있는 객체의 공통 규약

\- `TakeDamage(int damage)` 메서드를 `Player`와 `Boss`가 각자 구현



\### 객체 생성 및 관리 방법



\- `Player`와 `Boss`는 `GameMain.Initialize()`에서 1개씩 생성, 게임 재시작 시 `Reset()`으로 재사용

\- `Bullet`은 `Initialize()`에서 미리 여러 개(풀) 생성해두고, 필요할 때 비활성 객체를 꺼내 재사용하는 오브젝트 풀링 방식 사용

\- 텍스처(`G2Texture`)는 종류별로 한 번만 로드해서 같은 종류의 객체끼리 공유



\### 게임 상태 관리 위치



\- `GameMain` 내부 `GameState` enum(`Start`, `Playing`, `GameOver`)으로 관리

\- `Update()`/`Render()`에서 현재 상태에 따라 분기 처리
