# \## 1. 게임 개요

# 

# \- 프로젝트명: Boss Raid

# \- 장르: 탑다운 액션 (보스전)

# \- 플랫폼: PC (C#, glc2d)

# \- 개발 형태: 개인 과제 (기말고사)

# \- 한 줄 소개: 제한시간 안에 보스를 쓰러뜨리는 탑다운 원거리 액션 게임

# 

# \## 2. 게임 목표

# 

# \- 플레이어는 제한시간 안에 보스의 체력을 모두 깎아야 한다.

# \- 보스를 처치하면 승리, 제한시간이 0이 되거나 플레이어 체력이 0이 되면 패배한다.

# \- 남은 시간은 결과 화면에서 클리어 기록으로 표시한다. (예정)

# 

# \## 3. 핵심 설계

# 

# \### 3.1 시간 기반 요소 (제한시간형)

# 

# \- 카운트다운 타이머가 0이 되면 게임 오버

# \- 제한시간 값: 미정 (보스 체력과 플레이어 공격력을 기준으로 테스트 후 결정)

# 

# \### 3.2 액션 요소

# 

# \- 시점: 탑다운

# \- 플레이어 공격: 원거리

# \- 플레이어 이동 및 회피: 미정

# \- 보스 패턴: 미정

# 

# \## 4. 조작법

# 

# | 입력 | 동작 |

# | --- | --- |

# | 미정 | 이동 |

# | 미정 | 공격 |

# | 미정 | 회피 |

# 

# \## 5. 게임 상태

# 

# \- `Start` : 시작 화면

# \- `Playing` : 전투 진행

# \- `GameOver` : 결과 화면 (승리 / 패배)
