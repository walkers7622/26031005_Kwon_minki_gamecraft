## 게임 소개

탑다운 보스전 액션 게임입니다.  
플레이어는 아레나 안에서 보스의 돌진과 탄막을 피하고, 자동으로 발사되는 총알로 보스의 체력을 깎아 제한시간(90초) 안에 처치하는 것이 목표입니다.

## 조작 방법

|키|동작|
|-|-|
|↑ / ↓ / ← / →|플레이어 이동|
|Shift|대시 (이동 방향으로 짧게 돌진, 대시 중 무적, 쿨타임 있음)|
|Space (시작 화면)|게임 시작|
|Space (결과 화면)|게임 재시작|
|(자동)|총알은 별도 입력 없이 보스 방향으로 자동 발사|

## 게임 규칙

* 플레이어 HP 100으로 시작, 보스의 공격에 맞으면 HP 10 감소 (피격 후 1초 무적)
* 제한시간 90초 카운트다운, 0초가 되면 패배
* 보스는 3가지 패턴(돌진, 원형 탄막, 조준탄)을 사용하며, 체력 50% 이하에서 2페이즈로 전환되어 공격이 빨라짐
* 제한시간 안에 보스 HP를 0으로 만들면 승리
* 승리 시 남은 시간에 비례해 점수를 획득하고, 결과 화면에 표시됨

2. `F5`로 빌드 및 실행
3. 스페이스바를 눌러 게임 시작
